# Flow

个人离线项目管理应用。使用 **mygo v0.8.3 / Go 原生 UI**（随项目保留媒体与编辑器补丁，见 [补丁说明](third_party/mygo/FLOW_PATCHES.md)），界面组件来自 [Lobe UI 的 MyGo 组件库](https://mygo.lobehub.com)（随项目保留一处主题补丁，让组件使用 Flow 的配色，见 [补丁说明](third_party/lobe-mygo/FLOW_PATCHES.md)），图标为 Lucide；界面为卡片式风格：浅底上一块稍深的内容面板，任务、项目和记录是其上的白色圆角卡片，按钮与标签为胶囊形，主题色为紫色渐变；macOS 上通过 Metal 绘制，数据保存在本机 SQLite。界面参考已安装 Linear 的导航和任务组织方式；Flow 的代码、图标和数据模型独立实现。

## 打开应用

构建产物：

- [Flow.app](build/darwin-arm64/Flow.app)
- [macOS Apple Silicon 安装包](build/darwin-arm64/flow-0.1.1-arm64.dmg)

推荐打开 DMG 后将 Flow 拖到 Applications。首次启动可选择空白工作区或演示工作区。此版本为本地 ad-hoc 签名，未使用 Developer ID 公证；未验证 Intel Mac 或其他操作系统。展开的 app 也可用于本地预览；当前 iCloud 源目录会附加 Finder 元数据，正式分发请使用已验证的 DMG。

## 当前源码（对齐工作进行中）

上方 0.1.1 安装包是此前发布产物，下面新增能力需使用重新构建的应用。当前阶段状态和原生验收范围见 [实施验收表](docs/implementation-progress.md)。

- 项目：创建、编辑、状态、起止日期、项目标签、提醒、复制与深链接、收藏、概览、进度、归档、回收站恢复。
- 项目列表可切换跨项目时间线，支持周/月/季/年、缩放、依赖连线与拖动建立关系、联动排期、里程碑键盘导航。项目和任务可以排一段日期：在日期窗口的日历上先点开始日、再点结束日，或填“开始 → 结束”；只点一天就是截止日期。拖动条形会整段平移，拖动条形的左端或右端只改开始或结束日期。
- 任务：唯一 `FLW-` 编号、标题、富文本正文、状态、优先级、标签、日期、收藏和多层子任务。
- 状态分组列表、可横向滚动的看板、拖拽调整顺序或状态、批量修改状态/优先级及移入回收站。列表中从空白处（行两侧、分组标题、最后一行下方）按住拖出选框即可框选任务，拖到列表上下边缘会自动滚动；按住 `⌘` 或 `Shift` 开始时加选，在空白处单击取消选择。按在任务行上仍是打开或拖动该任务。
- 搜索标题、正文、编号；按项目、状态、优先级、标签筛选。工具栏的“筛选”菜单同时收纳高级筛选、保存为视图和清除筛选；已选条件显示为可逐个移除的标记。
- 可搜索的属性菜单，数字选择状态/优先级，多标签连续选择；列表和看板直接修改属性。
- 新建支持“继续创建”、跨启动草稿恢复、富文本说明，创建后保留原页面并提供打开入口。按用户要求移除模板、草稿、提醒与周期的独立导航入口。
- 中文与英文即时切换；命令面板提供上下文操作、分类搜索和分批加载，可搜索快捷键帮助；详情按当前列表顺序连续切换。
- 编辑自动保存，退出前刷新未保存内容；保存失败保留草稿并提供重试。
- 关系、阻塞与重复标记，重设父任务、复制含子任务的副本、转换为项目。
- 评论线程与嵌套回复、活动历史、说明版本恢复，以及带冲突检查的属性撤销。
- 单页面布局：顶部标题栏依次是侧栏开关、前进/后退、最近访问、面包屑和当前页面的操作，右端是命令搜索和新建按钮。侧栏只列所有任务、收藏、已收藏条目、视图和项目；“项目”标题即项目页入口，设置、归档项目、回收站和快捷键帮助是侧栏底部的图标。退出重开保留当前页面、筛选、历史与侧栏状态。
- 列表行为紧凑单行：状态与优先级为绘制的图标，标签显示为带色点的胶囊，截止日期临近或逾期时变色，含子任务的行显示完成数。勾选框和更多操作只在指针所在行或键盘聚焦行出现。列表不显示没有任务的分组；看板保留空列以便拖入，可在“显示”里关闭。
- 指针所在的任务行即为聚焦行，`S` / `P` / `L` / `X` / `Space` 直接作用于它；用键盘移动聚焦后，指针需再次移动才会重新取得聚焦。`Shift` 点击从上一次选中的行开始连选。
- 窗口足够宽时，任务详情在右侧显示属性栏，正文居中限宽；窄窗口和“列表与详情”布局中属性回到标题下方。面包屑依次列出列表和途经的任务。子任务、附件、关系等区块只在有内容时出现，添加入口在说明下方的“子任务”和回形针菜单以及标题栏的 ⋯ 菜单里；活动记录默认显示最近 5 条，可展开。
- 创建、保存等结果以右下角浮动提示显示并自动消失，不再推动页面内容。
- 设置支持浅色、深色和跟随系统，两种外观使用同一套卡片布局和紫色主题色，选择保存在本机；关闭窗口先保存并驻留，重新激活可继续编辑，`⌘ Q` 完全退出。
- `⌘ ⇧ N` 新建独立窗口，文件菜单也可将当前页面打开到新窗口。各窗口分别保留页面、筛选、侧栏和创建草稿，共享任务数据；“打开的窗口”菜单可切换或重新打开已关闭的窗口。
- 创建任务时可添加文件、粘贴图片/文件及拖入；文件随草稿保存，提交后归入任务，图片在正文内显示。`⌘ ⇧ U` 或 `/file`、`/insert` 添加附件。
- `Shift Enter` 在当前段落或列表项内换行；`/divider` 或 `___` 后按空格插入分隔线。`/collapsible section` 或 `>>>` 后按空格创建折叠内容，支持嵌套、收起/展开、整块操作、撤销、复制、草稿恢复和 Markdown/MCP 往返；表格仍在实现中。
- 本地文件与链接附件；任务内模板、周期与提醒操作仍可用。提醒在应用运行或重开时执行；完全退出期间只补建最近一期周期任务。
- 完整 JSON 工作区备份，恢复前自动保存旧工作区，校验后在单个事务内替换。
- 本地 stdio MCP：73 个项目/任务/视图/草稿/附件/关系/备份等工具，支持桌面端同时运行、实时刷新和只读模式。见 [接入说明](docs/mcp.md) 和 [本机构建配置](config/mcp.local.json)。

所有任务和子任务有独立状态；父任务完成不会自动完成子任务。回收站恢复只恢复同次删除的关联任务，保留此前单独删除的内容。回收站里可以永久删除单个任务或项目（悬停行尾的删除图标、右键菜单或任务页顶部），框选后批量恢复或永久删除，或“清空回收站”；永久删除前会确认，子任务、评论、附件、文档、提醒和历史一并删除，无法撤销。永久删除会留下一条很小的删除记录随 iCloud 同步，其他 Mac 合并时同样删除，不会被还原；另一台 Mac 在已删除项目里新建的任务会保留为无项目任务。项目进度统计包含未删除任务和子任务，排除取消及重复项。

首版面向个人本地使用，不包含账号、多人协作或 Linear 数据同步。关闭程序后无需运行任何服务；打包应用已包含 SQLite 动态库，使用时无需下载依赖。

评论现在使用富文本编辑器，支持格式、图片、文件、粘贴和撤销；任务/项目文档与项目更新使用相同的媒体导入。文件保存到所属任务或项目，发送/保存后的正文与图片可在重启后继续查看。

## 数据和备份

默认数据目录：`~/Library/Application Support/Flow/`，数据库为 `flow.db`。设置 › 数据位置 › “更改…”可把数据移到其他文件夹（复制并校验后重新启动，原数据库改名为 `flow.db.moved` 保留），或切换到已有 Flow 数据的文件夹；默认目录中的 `location.json` 记录新位置。移动后的文件夹不可用时（如外接磁盘未连接），Flow 打开默认目录并提示，不会在原路径新建工作区。数据库不能直接放进 iCloud 云盘（两台 Mac 同时打开会互相覆盖），选择 iCloud 中的文件夹时会改为用它做 iCloud 同步。可以通过设置页导出 `.flow.json` 备份；恢复会替换当前工作区，并先将旧工作区保留为 `backups/before-restore-*.flow.json`。这些备份也可以从设置页恢复。

备份保存正文结构、标签、父子关系、排序、回收站、草稿、模板、附件字节、历史、评论、周期计划和语言设置。文件上限为 512 MB，单个附件为 32 MB。备份不加密，应保存在合适的位置。不要在运行中手动复制 SQLite 主文件代替应用备份。

桌面会话独立保存在同目录的 `desktop-session.json`，不包含在工作区备份或 MCP 模型中；批量选择不跨启动恢复。

开发可设置 `FLOW_DATA_DIR` 使用独立目录。验收数据保存在项目的 `.local/acceptance/`，不写入默认工作区。

### iCloud 同步

设置 › iCloud 同步开启后，数据库仍留在本机，每台 Mac 把完整工作区写到 `iCloud 云盘/Flow/Devices/<设备>.flow.json`（每个文件只有一台 Mac 写，格式即备份；在 iCloud 文件夹内可直接恢复），并每 3 秒检查其他 Mac 的文件，按记录和字段做三方合并：两台 Mac 改了同一任务的不同字段都会保留；改了同一字段时以较晚修改为准；离线时各自新建的任务编号冲突会自动重新编号。无法合并的修改（如两台 Mac 让两个项目互相依赖）保留本机版本，对方的文件存入 `backups/sync-conflict-*.flow.json` 并提示。第二台 Mac 加入时可选择合并或改用 iCloud 中的数据（本机数据先备份到 `backups/before-sync-*.flow.json`）。附件文件不在这些 JSON 里：每个文件按内容的 SHA-256 命名，只存一份在 `iCloud 云盘/Flow/Files/<sha256>`，写入后不再改动，所以只上传一次；之后的编辑只重写不含附件的 JSON。其他 Mac 先拿到 JSON、附件还在下载时会等附件到齐再合并，设置页显示"正在从 iCloud 下载附件…"；iCloud 为节省空间只留在云端的附件会请求下载。没有任何设备再引用的附件，在本机连续一周看到无人引用后删除；有设备的 JSON 读不到时不删除任何附件。同步冲突时存下的 `sync-conflict-*.flow.json` 含完整附件，可单独恢复。同步状态和进度保存在数据目录的 `sync/` 中。已知限制：两台 Mac 同时运行且同一周期任务到期时，可能各生成一份；同步依赖 iCloud 云盘自身的上传下载，延迟从几秒到几分钟不等；旧版本 Flow 读不了附件分开存放的同步文件，会跳过它们直到更新。

## 自动更新与发布

Flow 内置基于 MyGo `mygo.Updater` 的应用内自动更新（Ed25519 签名校验 + 增量 delta 更新），全部界面以 Lobe UI 风格集成在应用内部：

- **检查更新**：启动后后台自动检查（每 24 小时一次），也可随时通过菜单栏「Flow › 检查更新…」、命令面板（`⌘ K`）或「设置 › 软件更新」手动检查。
- **更新体验**：发现新版本时在顶部显示可关闭提示条并在侧栏设置图标显示提示点；应用内更新弹窗展示版本变更与 Markdown 更新日志，支持「跳过此版本」「稍后提醒」「下载并安装」和实时下载进度条；安装就绪后支持「立即重启并更新」，并在退出前自动保存所有未保存草稿。
- **设置项**：可在「设置 › 软件更新」中开关「自动检查更新」与「自动下载更新」（偏好保存在数据目录的 `updater.json` 中）。
- **发布流程**：`mygo.json` 已指向 GitHub 公开仓库 `Lorpaves/flow` 与 Ed25519 公钥。发布新版本时更新 `mygo.json` 版本号与 `CHANGELOG.md`，提交并推送 `vX.Y.Z` 标签即可由 `.github/workflows/release.yml` 自动构建签名更新包、上传并自动正式发布为 GitHub Release（含 `-` 后缀的标签会自动标记为 Pre-release）；本地也可使用 `MYGO_UPDATER_PRIVATE_KEY="$(cat ~/Library/Application\ Support/mygo/update-keys/mygo-update.key)" make release` 构建并上传。

## 开发和构建

需要 Go；Makefile 在当前命令中选择 Go 1.27.3，不修改全局 Go 配置。首次开发构建需要联网下载模块及 mygo 原生依赖。

```sh
make dev       # 独立 .local/dev 工作区，支持热重载
make check     # 测试及 mygo 静态检查
make build     # 原生 app 与 DMG
make icon      # 重新生成代码绘制的图标
make mcp       # 独立 stdio MCP 可执行文件
```

竞态检查使用 `GOTOOLCHAIN=go1.27.3 CGO_ENABLED=1 go test -race ./...`。发布程序使用 `CGO_ENABLED=0`。

主要代码：`internal/core` 管理模型、事务和备份；`app.go` 管理后台存储队列和编辑草稿；`ui_*.go` 实现界面。数据库及备份当前版本为 9，兼容旧数据库和备份 v1–v8；旧应用会拒绝打开更新的数据库。

正文粘贴支持保存 HTML 内嵌图片和可访问的 HTTP(S) 图片，保留文本格式和段落次序。跨任务粘贴及模板使用会保存独立附件副本；删除源附件或模板不会使新副本失效。只有图片、没有标题和文字的未完成内容也会自动保存。图片读取失败时整次粘贴保持未插入，可重试或改用本地文件。
